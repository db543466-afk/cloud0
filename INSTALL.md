# Установка SexyClean 3.0

Инструкция по установке и запуску новой версии на **Windows 10/11**. Есть два пути: запуск из исходников (быстро, для проверки) и сборка автономного **EXE** (чтобы запускать без Python).

---

## 1. Требования

- **Windows 10 или 11** (64‑бит).
- **Python 3.10 или новее** — скачайте с [python.org](https://www.python.org/downloads/windows/). При установке обязательно отметьте галочку **«Add python.exe to PATH»**.
- Доступ в интернет для загрузки зависимостей (`pip`).

Проверить, что Python установлен, можно в командной строке (`cmd`):
```bat
python --version
```

---

## 2. Получение новой версии

**Вариант с git:**
```bat
git clone https://github.com/db543466-afk/cloud0.git
cd cloud0
git checkout claude/sexyclean-ccleaner-400f411d075e805aab6b00a931c4ad32
```

**Вариант без git (ZIP):** скачайте архив ветки — [cloud0 (ветка апгрейда) .zip](https://github.com/db543466-afk/cloud0/archive/refs/heads/claude/sexyclean-ccleaner-400f411d075e805aab6b00a931c4ad32.zip) — и распакуйте в удобную папку.

> После слияния PR новую версию можно будет брать прямо из ветки `main`.

---

## 3. Запуск из исходников

Самый простой способ — двойной клик по **`run.bat`** в папке проекта. Он сам поставит зависимости и запустит приложение.

Либо вручную в `cmd` из папки проекта:
```bat
python -m pip install -r requirements.txt
python sexy_cleaner.py
```

Откроется окно SexyClean 3.0.

---

## 4. Сборка EXE (автономный запуск без Python)

Самый простой способ — двойной клик по **`build.bat`**. Он поставит зависимости и PyInstaller и соберёт приложение.

Либо вручную:
```bat
python -m pip install -r requirements.txt pyinstaller
python -m PyInstaller --noconfirm --clean --windowed --name "SexyClean" --add-data "assets;assets" sexy_cleaner.py
```

Результат появится в папке **`dist\SexyClean\`**, запускаемый файл — **`dist\SexyClean\SexyClean.exe`**. Папку `SexyClean` можно целиком скопировать на другой компьютер и запускать там без Python.

**Нужен один файл вместо папки?** Добавьте флаг `--onefile`:
```bat
python -m PyInstaller --noconfirm --clean --windowed --onefile --name "SexyClean" --add-data "assets;assets" sexy_cleaner.py
```
Тогда получится один `dist\SexyClean.exe` (запускается чуть дольше — распаковывается во временную папку).

---

## 5. Обновление с версии 2.0

Это то же приложение, поэтому обновление = замена файлов на новые и, при необходимости, пересборка EXE:

1. Замените `sexy_cleaner.py`, `requirements.txt`, папку `assets` и `README.md` новыми (или сделайте `git pull` / `git checkout` нужной ветки).
2. Переустановите зависимости: `python -m pip install -r requirements.txt`.
3. Если пользуетесь EXE — соберите заново (пункт 4).

Настройки/данные приложения нигде не перезаписываются. Отключённые через раздел «Автозагрузка» ярлыки лежат в резервной папке `%LOCALAPPDATA%\SexyClean\StartupDisabled` и при обновлении не трогаются.

---

## 6. Права администратора

Большинство функций работает без прав администратора. Запуск **от имени администратора** (ПКМ по `SexyClean.exe` → «Запуск от имени администратора») нужен только для:

- очистки категории «Временные файлы Windows» (`C:\Windows\Temp`);
- очистки корзины и запуска сканирования Microsoft Defender (могут дополнительно запросить подтверждение UAC).

---

## 7. Возможные проблемы

- **`ModuleNotFoundError: No module named 'PySide6'`** — не установлены зависимости. Выполните `python -m pip install -r requirements.txt`.
- **`'python' не является внутренней или внешней командой`** — Python не добавлен в PATH. Переустановите Python с галочкой «Add to PATH» или используйте `py` вместо `python`.
- **Нет фонового изображения** — при сборке EXE не передан `--add-data "assets;assets"`. Пересоберите с этим флагом. Можно заменить `assets\sexyclean_wallpaper.png` своим изображением, сохранив имя файла.
- **Windows SmartScreen при запуске EXE** («Windows защитила ваш компьютер») — это обычное предупреждение для неподписанного приложения: «Подробнее» → «Выполнить в любом случае».
- **Антивирус ругается на свежесобранный EXE** — частое ложное срабатывание на сборки PyInstaller. Добавьте файл в исключения или подпишите приложение сертификатом.

---

## 8. Безопасность

SexyClean удаляет файлы **только в корзину** и **только после подтверждения**, строго в пределах известных папок кэша и временных файлов. Реестр и системная автозагрузка не изменяются. Приложение не заменяет антивирус.
